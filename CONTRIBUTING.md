# Contributing / المساهمة

Thanks for improving YAML Doctor. Please keep changes focused, safe, and testable.

1. Fork/branch from `main` and use Python 3.10+.
2. Install with `python -m pip install -e . pytest`.
3. Add or update tests for behavior changes and run `python -m pytest`.
4. Do not commit secrets, private configuration, generated artifacts, or real production YAML.
5. Keep public behavior documented in the bilingual README.
6. Open a pull request explaining the problem, approach, and validation performed.

For security issues, follow `SECURITY.md` instead of publishing sensitive exploit details.

---

نرحب بالمساهمات المركزة والقابلة للاختبار. استخدم Python 3.10+، شغّل الاختبارات قبل إرسال Pull Request، ولا ترفع أسرارًا أو إعدادات إنتاج حقيقية أو ملفات مولدة. يجب توثيق أي تغيير في السلوك العام داخل README باللغتين عند الحاجة. للمشكلات الأمنية اتبع `SECURITY.md`.
